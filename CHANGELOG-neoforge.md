# Changelog

## [26.2.0-3.1.3] - 2026-07-29
- Updated Pedestal block property handling to avoid mutating vanilla block properties and causing startup crashes with other mods.

## [26.2.0-3.1.2] - 2026-07-25
- Fixed several issues affecting Light blocks.

## [26.2.0-3.1.0] - 2026-06-22
- Update to 26.2.
- Added de_de translation.

## [26.1.2-3.1.0] - 2026-04-13
- Added support for Minecraft 26.1.2.
- Added comparator output support for Pedestals.

## [26.1-3.0.2] - 2026-04-02
- Added support for Minecraft 26.1.1.

## [26.1-3.0.1] - 2026-03-28
- Added a crafting recipe and recipe book unlocking for the Light Wand.

## [26.1-3.0.0] - 2026-03-28
- Update to 26.1.
- Added the Light Wand to switch supported flames into Light mode.
- Added Quartz Block lamps/torches and Quartz Block / Quartz Bricks variants for standing torches and fire pits.
- Added creative tab controls to reverse the item order and sort entries by color.
- Added dynamic surface fire textures derived from the underlying material, with a config option to keep them static.
- Major internal refactor for maintainability and platform parity.

## [1.21.11-2.2.0] - 2025-12-13
- Update to 1.21.11
- In-game config screen (Mods -> Additional Lights) to enable/disable Fire/Soul Fire crafting recipes (default: off).
- Recipe book unlocking (advancements) for all Additional Lights recipes.

## [1.21.10-2.1.13] - 2025-10-31
